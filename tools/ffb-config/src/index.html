Race

Works offline — listens for Le Mans Ultimate Telemetry Socket JSON on UDP. When the base is connected, the same session injects rim Telemetry frames over CDC. While race mode is on, closing the window hides to the tray.

Plugin setup: copy LeMansUltimateTelemetryPlugin.dll into LMU Plugins, enable telemetry+scoring in UserData/player/CustomPluginVariables.JSON, then launch the game.
