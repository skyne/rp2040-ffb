Rim / accessories

WS2812 DIN → rim GP14 (11 LEDs). Encoders → HID up/down. Sync on Apply/Save.

Shift LED test

Layout: LED0–1 flags · LED2–8 RPM (pit = yellow blink) · LED9–10 TC/ABS — single signal blinks both; two alternate; red = urgent

On-device firmware

Filled from Dump / connect (base_fw / rim_fw). Match pack fw_id.

Firmware update

Prefer a release pack from scripts/pack-firmware.sh (ffb-firmware-*.zip): updates rim via OTA, then reboots base into BOOTSEL and copies base.uf2. After reconnect, Dump and compare base_fw / rim_fw to the pack's fw_id (same string on both MCUs when built from one pack). Or flash rim alone with a .bin/.uf2.
